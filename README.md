# Rosette

ANNOUNCEMENT [6/7/26]: THIS PROJECT AIMS FOR BROAD SYSTEMS SUPPORT THROUGH A VARIETY OF SOFTWARE TESTS, AND IS INTENDED FOR USE IN XENIA/XENIA CANARY EVENTUALLY. 

Rosette is a x86 to NEON translator that implements a zero-trust DBT/framework layer that provides substantive ABI handshake checks, as a means of confirming compatibility across various Macs. It is the alternative to Rosetta 2 once Apple drops support in 2028.

For UNLV Students:
I highly recommend installing the latest version of Rosette from the Releases page, using the custom installer and uninstaller (at the moment, there is no updater). Please send any issues with the application to either u/ryanwisemanmusic (Reddit) or ryanwisemanmusic@gmail.com.
