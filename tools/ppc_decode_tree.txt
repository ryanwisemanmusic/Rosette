# Rosette PPC decode tree.
#
# The Xenon PowerPC decoder is a two-level decision tree: the 6-bit primary
# opcode selects a case, and each case runs one or more switches over a
# concatenation of extended-opcode bit ranges. VMX128 shares primary opcodes 4,
# 5, and 6 with AltiVec, so the order of the switches inside a primary is part
# of the contract - the more specific VMX128 switch must run first.
#
# Grammar:
#   primary <n>              open the case for primary opcode n
#   hit <mnemonic>           the whole primary decodes to one instruction
#   switch a:b:s[,a:b:s...]  switch over concat(bits[a..b] << s, ...)
#     <binary> <mnemonic>    one case of the switch just opened
#
# Bit numbering is PowerPC's: bit 0 is the most significant bit of the 32-bit
# instruction word. Transcribed from the Xenon decode tables. Consumed by
# tools/gen_ppc_decoder.py.
