Direct cached register operands

Three native CPU areas now use the existing private register cache: wide variable shifts/rotations, register sign/zero extensions and dead-flag register multiplication. This removes temporary register moves. Live flag outputs and narrow merges keep the original paths; memory retains its existing TLB, helper, fault and ordering checks.

Each row compares the final implementation with its internal direct_register_operands control. Seven alternating ReleaseFast pairs run after compilation. Timed work includes complete native block entry, exit and publication; setup and compilation are excluded. Full state, memory/helper counts and retirement are checked. The combined row measures the changes together: other ratios must not be multiplied. Small resident blocks do not model Halo's full instruction-cache working set or establish a frame-critical fraction.

Where CPU demand remains


  • MAIN uses 368.272 s CPU over 395.009 s elapsed, executing 7.489 billion blocks and 215.422 billion retired instructions. RENDER uses 213.768 s CPU / 8.060 billion blocks. The previous native-path templates are active. Native execution is a broad candidate, but its exclusive useful CPU and per-frame critical share are unmeasured.
  • GPU Commands uses 259.261 s CPU; XThread0022 / 0023 use 270.699 / 266.784 s. Both XThreads still sample the spin-acquisition region. Samples do not attribute all CPU to that region. No thread reassignment or synchronization weakening was made.
  • Outermost Vulkan bridge spans total 77.072 s elapsed across 22.802 million calls, max 177.159 ms. Descriptor binding totals 11.265 s, pipelines 6.082 s, fences 5.167 s. These are wait-inclusive overlapping spans, not removable CPU or actual GPU execution time.
  • Frame queue host spans total 10.804 s, max 28.257 ms; readback 1.088 s / 42 calls, max 168.259 ms; WSI present 52.530 ms total. FSI evidence IO totals 13.515 s on the background worker, max 360.848 ms. Background worker time is not shader creation latency.
  • Configuration is valid, 62,470 bytes, render target path unset / readback none / occlusion fast. This is not a matched FSI profile. The larger 15.357 s historical cadence maximum is a gap, not an identified CPU function to accelerate. Actual GPU execution and synchronization critical-path fractions remain unresolved.
