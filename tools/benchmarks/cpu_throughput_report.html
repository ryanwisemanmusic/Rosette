Five areas · six independent controls

1. Packed protection updates. Change up to 32 page states with one atomic word store, count exactly which pages changed, and preserve the table writer lock, protection epochs, leaf lifetime and invalidation protocol. Boundary and partial-word updates retain unrelated page bits.

2. One classification per page. An operand wholly inside a page needs one protection lookup. Spanning or wrapping operands still inspect both ends. This changes no permission or fault-handling policy.

3. Producer diagnostics. A bounded index caches the ledger's first matching site, including misses valid for that table length. Appending and resetting invalidate appropriately. Production notifications also stop taking the clock mutex for a snapshot the ledger discards. Step/caller/signal evidence remains identical; guest time is untouched.

4. Exact log10 import lane. Reuse the ordinary CRT implementation and the existing calling-context/TSO/eligibility protocol while avoiding the general runtime lock. No approximate math; diagnostics and recursion retain ordinary dispatch.

5. Native vector rearrangements. Twelve pure VEX.128 register forms retain XMM values in native registers between operations. Memory, helper, observer, legacy and wide boundaries still publish state. All destination/source aliases and 256 immediate values are checked against eager native publication.

Seven alternating ReleaseFast pairs, after validation compilation and without concurrent builds. Same final implementation with one named control disabled/enabled.
